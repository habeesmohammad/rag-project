# RAG Document Intelligence

A Streamlit app that lets you upload PDF files and ask questions about them using Retrieval-Augmented Generation (RAG). Everything runs locally: embeddings come from Hugging Face and answers are generated by a local LLM through Ollama.

## Features

- Upload one or more PDFs
- Automatic text splitting and embedding (`sentence-transformers/all-MiniLM-L6-v2`)
- Fast similarity search with FAISS
- Answers generated locally with Ollama (`llama2`)
- Source passages and page numbers shown for each answer
- Skips duplicate uploads and lets you clear all documents

## Tech Stack

Streamlit, LangChain, FAISS, Hugging Face sentence-transformers, Ollama

## Prerequisites

- Python 3.10 or newer
- [Ollama](https://ollama.com) installed and running

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/habeesmohammad/rag-project.git
   cd rag-project
   ```

2. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # macOS / Linux
   source venv/bin/activate
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Pull the model and start Ollama:
   ```bash
   ollama pull llama2
   ollama serve
   ```

## Run the App

```bash
streamlit run app.py
```

Then open the URL shown in the terminal (usually http://localhost:8501).

## Usage

1. Upload a PDF from the sidebar. A sample, `test_doc.pdf`, is included.
2. Wait for it to be processed.
3. Ask a question in the chat box, for example: *"What are the key applications of AI in healthcare?"*
4. Expand **View Sources** to see which passages the answer came from.

## Troubleshooting

- **"Could not connect to Ollama"**: make sure `ollama serve` is running.
- **Model not found**: run `ollama pull llama2`.
- **First run is slow**: the embedding model is downloaded once from Hugging Face.
